Essential Insights

Readiness and data-quality checks, limited numeric/categorical/date descriptives when supported, up to four supported static visuals, evidence-bound findings, and prioritized correction guidance for one eligible dataset.

  • Input: one properly de-identified UTF-8 CSV
  • Controlled-beta limits: 5 MB, 10,000 data rows, 100 columns, 64 characters per field name, and 75 categories per categorical field
  • Allowance: one final assessment plus two correction attempts for the same dataset
  • Downloads: PDF summary, long-form analysis CSV, and one combined PNG visual summary
  • Processing: browser-local; the selected source file is not uploaded to ProgramMetrics for analysis
